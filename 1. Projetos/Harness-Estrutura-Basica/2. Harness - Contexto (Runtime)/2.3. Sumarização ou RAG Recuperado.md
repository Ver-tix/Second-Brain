# Sumarização e RAG Recuperado: Otimizando o Espaço do Contexto

## O problema que essa camada resolve

O Buffer cresce a cada turno da conversa. A Memória de Longo Prazo (RAG/Grafo) tem potencialmente milhões de documentos indexados. Nenhum dos dois pode ser despejado inteiro na context window — o custo de tokens explode e a atenção do modelo se dilui.

Duas técnicas resolvem esse gargalo, e ambas têm o mesmo destino final: **um pedaço enxuto de texto dentro do Contexto de Runtime.**

## 1. Sumarização (Compactando o Buffer)

Quando o histórico de conversa ultrapassa um limite de tokens, em vez de truncar (e perder informação do início da conversa), o sistema roda uma etapa de resumo:

```
[ Buffer Longo: 50 mensagens ]
        │
        ▼
[ Sumarizador (LLM auxiliar ou heurística) ]
        │
        ▼
[ Resumo Compacto: "Usuário pediu X, decidimos Y, pendências: Z" ]
        │
        ▼
[ Injetado no início do novo Contexto ]
```

- **Vantagem:** preserva a continuidade da conversa sem pagar o custo total de tokens.
- **Risco:** perda de nuance — detalhes específicos podem não sobreviver ao resumo. Por isso, dados críticos (números exatos, decisões formais) devem ir para Memória de Longo Prazo estruturada, não depender só do resumo.

## 2. RAG Recuperado (Trazendo a Memória de Longo Prazo para o Contexto)

Quando o agente consulta o RAG vetorial, o GraphRAG ou os Reflection Logs (ver [[1.1. Estruturas de Memória]]), o resultado dessa busca — os _top-k_ trechos mais relevantes — é injetado dentro do Contexto de Runtime antes da geração da resposta final.

```
[ Query do usuário ]
        │
        ▼
[ Busca Vetorial / GraphRAG / Episódica ]
        │
        ▼
[ Top 2-3 trechos mais relevantes ]
        │
        ▼
[ Injetados no Contexto junto com System Prompt + Buffer ]
```

## Por que isso pertence ao Contexto, não à Memória de Longo Prazo

Uma vez recuperado, o trecho de RAG deixa de ser "memória persistida em banco" e passa a ser só mais um texto competindo por atenção na context window — exatamente como o Buffer ou o System Prompt. A Memória de Longo Prazo é o **armazenamento**; isso aqui é o **transporte** desse armazenamento até o modelo.
