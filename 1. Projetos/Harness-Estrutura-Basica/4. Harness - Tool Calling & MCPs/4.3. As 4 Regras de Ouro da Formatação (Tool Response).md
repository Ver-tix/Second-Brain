Para devolver dados à LLM de forma limpa, aplicamos um **filtro intermediário (middleware)** antes que a resposta chegue ao modelo.

```
[ API Externa / DB ] ──► (JSON Bruto Enorme) ──► [ Filtro/Middleware ] ──► (JSON Enxuto) ──► [ Agente (LLM) ]
```

### 1. Filtragem e Seleção de Campos (_Field Pruning_)

Remova tudo o que não for estritamente necessário para responder ao objetivo do usuário.

- **Retorno Bruto da API (Exemplo da API do Tempo):**
    ```JSON
    {
      "status_code": 200,
      "request_id": "req_8f7392a01",
      "server_time_epoch": 1723632000,
      "location": {
        "city": "Fortaleza",
        "region": "Ceará",
        "country": "Brazil",
        "lat": -3.7319,
        "lon": -38.5267,
        "timezone_id": "America/Fortaleza"
      },
      "current": {
        "temp_c": 30.0,
        "temp_f": 86.0,
        "feelslike_c": 34.2,
        "condition": { "text": "Sunny", "code": 1000, "icon": "//cdn.weather.com/1000.png" },
        "wind_kph": 18.5,
        "wind_degree": 90,
        "humidity": 75,
        "uv": 8.0
      }
    }
    ```
    
- **Retorno Filtrado para o Agente:**
    ```JSON
    {
      "city": "Fortaleza, CE",
      "temperature": "30°C (sensação de 34°C)",
      "condition": "Ensolarado",
      "humidity": "75%"
    }
    ```
    

### 2. Formato Amigável: JSON Compacto vs. Markdown

As LLMs modernas processam **JSON minificado/compactado** ou até mesmo **chaves Markdown/Texto Plano** de forma muito eficiente:

- **Opção A: JSON Minificado (Economiza Espaço)**
    ```JSON
    {"city":"Fortaleza","temp":"30C","condition":"Sunny","humidity":"75%"}
    ```
    
- **Opção B: Texto Chave-Valor (Ainda Mais Leve)**
    ```Plaintext
    Cidade: Fortaleza
    Temperatura: 30°C
    Condição: Ensolarado
    Umidade: 75%
    ```
    

### 3. Truncamento de Listas Longas (_Pagination & Clipping_)

Se a ferramenta for uma busca no banco de dados ou no Google, a resposta pode retornar centenas de resultados.

- **Nunca envie mais do que 3 a 5 resultados por vez** na resposta da ferramenta.
    
- Se necessário, adicione uma flag indicando que há mais dados disponíveis:
    ```JSON
    {
      "results_found": 150,
      "showing_top": 3,
      "items": [ ... ],
      "has_more": true
    }
    ```

### 4. Resumo/Extração Prévia para Documentos Grandes (Small RAG)

Se a ferramenta ler um PDF, página web ou arquivo extenso:
- **Não injete o texto do documento inteiro** de volta no contexto do agente.
- Execute uma função rápida em código Python que resume ou extrai apenas os parágrafos relevantes à query antes de responder à ferramenta.
## O Fluxo Completo de Mensagens na API

No protocolo nativo (como OpenAI / Anthropic / Google), a troca de mensagens na memória da conversa fica estruturada assim:

```JSON
[
  {
    "role": "user",
    "content": "Como está o tempo em Fortaleza hoje?"
  },
  {
    "role": "assistant",
    "tool_calls": [
      {
        "id": "call_abc123",
        "name": "get_weather_forecast",
        "arguments": "{\"location\":\"Fortaleza, CE\"}"
      }
    ]
  },
  {
    "role": "tool",
    "tool_call_id": "call_abc123",
    "content": "{\"city\":\"Fortaleza, CE\",\"temp\":\"30°C\",\"condition\":\"Ensolarado\"}"
  },
  {
    "role": "assistant",
    "content": "O tempo em Fortaleza hoje está ensolarado, com temperatura em torno de 30°C."
  }
]
```

Note como a mensagem da `role: "tool"` fica enxuta. O agente lê aquele pequeno JSON e gera a resposta final amigável em linguagem natural para o usuário.
