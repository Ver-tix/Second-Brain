# Passo 2 - Sons e Letras
### 1. Blending
Criar novas palavras ao combinar já existentes. 
- Exemplo: imagine quando a palavra "mash" foi criada. Também outras palavras, como "bat" e "smack" foram criadas. Elas serviram de ingrediente para criar palavras como "smash" (mash + smack) e "bash" (bat + mash). Foi-se repetidamente inserido um fragmento de "mash", no caso, "ash", em outras palavras novas. Isso ocorre repetidamente em diversas outras palavras, como em:
	- Sons de "Gl" em termos derivados de "light" (luz), como glimmer, glisten, glean, glitter glint
	- Sons de "Sn" em derivados contextuais de "mouth" (boca) e "nouse" (nariz), como snore, snack, sneeze, snout e sniff
### 2. Fluência Perceptiva
O nome "kiki" combina mais com formas arredondadas ou afiadas e pontiagudas? O mesmo pergunto para o nome "Bouba".

Provavelmente você associou "Kiki" a formas afiadas e "Bouba" a formas arredondadas. Isso porque Kiki tem letras, com vértices afiadas - "k" e "i" - e Bouba tem letras com formas arredondas - "b", "o", "u", e "a" minúsculo que também é arredondado.

### 3. Fluência Sinestésica
Pense em nomescomo "Grimmey" e "Gromey". Qual dos dois são mais facilmente associadas a uma marca de facas? O primeiro! Pense em quando pronunciamos o "i", movimentamos nossa boca de forma mais afiada; já no "o", pronunciamos de forma mais arredondada na boca.

# Passo 3 - Crie Nomes em Potencial
### Em Caso de Usar o Tipo Neologístico
1. **Comece com prefixos significativos**. Prefixos são importantes devido à leitura sequencial do cérebro humano. Lista de Phonastemos: 

| Prefixo | Significado                | Exemplos                 |
| ------- | -------------------------- | ------------------------ |
| Bl -    | Explodir (Blow)            | blast, blurt, blaze      |
| Br -    | Brilhante (Bright)         | breezy, brisk, brilliant |
| Cl -    | Barulho (Clang)            | clank, clash, clap       |
| Cr -    | Enérgico, Irritado(Cranky) | crabby, crazy, cry       |
| Dr -    | Arrastar (Drag)            | drift, droop, drape      |
| Fl -    | Fluxo (Flow)               | float, flush, flee       |
| Fr -    | Frenético (Frantic)        | frazzle, fray, freaky    |
| Gl -    | Brilho (Gleam)             | glow, glint, glass       |
| Gr -    | Rosnar (Growl)             | grunt, groap, gruff      |
2. **Organize os sons da frente para trás** (Palavras direcionais).
	- Alguns sons são produzidos na frente da boca, como "b", "p" e "m"; já outros, na parte de trás da boca, como "k" e "h"
	- Sons de nomes devem começar por sons na frente da boca, e seguir até a parte de trás da boca. Veja a tabela de lista de letras e posição na boca

| Mais para trás possível |     |     |     |     | Mais para frente possível |
| ----------------------- | --- | --- | --- | --- | ------------------------- |
|                         |     |     | T   |     |                           |
|                         |     |     | D   |     |                           |
|                         |     |     | S   |     | K                         |
|                         |     |     | Z   | Ch  | G                         |
| B                       |     |     | N   | J   | H                         |
| M                       | F   |     | L   | Sh  | NG                        |
| W                       | V   | Th  | R   | Y   | W                         |
- **A sequência deve ficar**:
	- Prefixo $\rightarrow$ palavra de [[#3. Fluência Sinestésica|Fluência Sinestésica]] $\rightarrow$ consoantes direcionais acima (listadas na tabela acima)

3. **Sufixos**
	- Você deve pesquisar "sufixos e latim" na internet (a melhor lista vem da Wikipedia). Recomendo o "Latin Derivational Suffixer", que são usadas para criar palavras novas
	- Nas subcategorias, escolha [[Latin Noun-Forming Suffixes]]" para associar a produtos; e "[[Latin Verb-Forming Suffixes]]" ara serviços, para que soem como uma ação.
	- Você também pode considerar adições de sufio relativas ao gênero da palavra (masculino, feminino)
### Em Caso de Usar o Tipo Associativo
Faça um mapa mental dos significados que você quer passar, e use técnicas como:

| técnica      | Exemplo                                                           |
| ------------ | ----------------------------------------------------------------- |
| Blend        | dictionary + picture = Pictionary                                 |
| Prefixo      | Web + MD = WebMD; Turbo + Tax + TurboTax                          |
| Sufixo       | Shop+ify = Shopify; Bit + ly = Bitly                              |
| Remoção      | Excellent - lent = Excel; Accurate - te = Accura                  |
| Substituição | Video + m = Vimeo; Emotion + v = Evotion; Cognition + v = Cognivo |
| Homófono     | Fantastic  k = Fantastik; Crispy Creme + k = Krispy Kreme         |
| Onomatopéia  | Som do produto: Wii lembra "we" ("nós")                           |
| Tradução     | Volvo = "I Roll" em latim; Ubuntu = "humanidade" em zulu          |
| Acrônimo     | International Business Machine = IBM; General Eletric = GE        |
| Rima/Ritmo   | Etch-a-Sketch; Fitbit; Behavior Savior; AlignMind                 |
| Fundador     | Ben&Jerry's, Disney, Burberry's                                   |
### Em Caso de Usar o Tipo Descritivo
Essa seção vai ser curta. É raro usar essa categoria. Tente aliterações (Best Buy) ou incorpore a extensão do domínio do website ao nome (ex.: "attitude", com extensão ".media" = "Attitude.media"; "optimize" com extensão ".design" = "optimize.design").

>[! o que são extensões de domínio]
>Nada mais são que ".com", ".co", ".io", "blog"
>
### Em Caso de Usar o Tipo Desvinate
Queremos descobrir quais emoções queremos que o cliente experiencie, então iremos buscar por instâncias dessas emoções em contextos fora do nosso negócio:
1. Converter emoções em rótulos (ex.: uma empresa quer representar o fascínio e o sentimento intrigante da descoberta nas pesquisas, e escolhe termos como "awe" ou "wow")
2. Expanda o mapa semântico. Quais contextos em que uma pessoa pode experienciar esse sentimento? (ex.: ainda no caso do "awe" ou "wow", onde temos esse tipo de sensação? Na natrueza, no pico de um monte, como o Everest, ou em Parques nacionais - Apple usou parque snacionais para criar seus produtos inicialmente -; ou no espaço, com termos como Nebula, Aurora, Borealis, Chasma, etc.)
